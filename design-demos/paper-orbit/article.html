一个个人网站不需要从复杂开始。先让最小的内容路径稳定运行，再逐步加入主题、评论和更丰富的页面。

01 / PREPARE

准备第一圈轨道

域名负责让人找到网站，仓库保存文章和配置，静态生成器把 Markdown 转成 HTML。把这三个角色分清，后面的选择会简单很多。

当前选择

本站已经使用 GitHub Pages，不再依赖持续运行的云服务器。

02 / CHOOSE

选择发布路径

静态博客更适合交给静态托管平台。云服务器拥有更多自由，但也需要承担系统维护、证书更新与故障处理。

推荐GitHub Pages

免费、自动部署，适合静态博客。

需要后端时云服务器

自由度高，也需要持续维护。

03 / BUILD

让内容自动抵达

构建任务应该从干净环境开始，安装依赖、生成页面，再发布到 Pages。这样本地与线上使用同一套过程。

01 npm ci
02 npm run build
03 deploy to GitHub Pages
04 / VERIFY

确认轨道闭合

访问最终域名，逐项检查首页、文章、HTTPS 和移动端。部署状态与真实访问结果都正常，才算完成。

  • 首页与文章页PASS
  • HTTPS 与域名PASS
  • 手机阅读体验PASS
