本指南涵盖从注册域名到上线运营的全流程。重点不是记住命令，而是理解域名、源码、构建产物和托管平台之间怎样连接起来。

01

开始之前

个人博客可以托管在云服务器，也可以部署到专门的静态托管平台。两种方式都能工作，选择主要取决于你是否愿意持续维护服务器。

现在本站采用 GitHub Pages。源码推送到主分支后，GitHub Actions 自动构建并发布，不再依赖持续运行的云服务器。

02

选择部署方案

方案优势适合
GitHub Pages免费、零运维静态博客
云服务器自由度高需要后端服务
Vercel / Netlify预览方便前端项目

03

生成静态网站

文章保存在 Markdown 文件中，生成器负责把它们转换成浏览器可以直接访问的 HTML、CSS 和 JavaScript。

# 安装依赖并生成静态文件
npm ci
npm run build

# 本地预览
npm run dev

构建目录不需要提交到仓库。持续集成任务会在每次发布时重新生成，源码始终是唯一可信来源。

04

上线与验证

部署成功不只意味着任务显示绿色。还要确认自定义域名、HTTPS、主要页面、移动端布局和旧链接都能正常工作。

  • ✓首页、文章页与项目页返回 200
  • ✓根域名和 www 使用 HTTPS
  • ✓手机与桌面阅读宽度合理
  • ✓保留可回退的版本标签
