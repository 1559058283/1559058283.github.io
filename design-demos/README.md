# aitechflow.cn redesign directions

## Round 2 — Innei / Yohaku inspired

These directions preserve the warmth, whitespace, Chinese reading rhythm, and subtle motion that the user liked in Innei, while changing the layout and visual system.

| Direction | Core idea | Deliberate variation |
| --- | --- | --- |
| Afterglow Index / 余温索引 | Warm editorial index with dated writing, profile notes, and project status rows | Asymmetric magazine layout instead of a Yohaku content feed |
| Quiet Circuit / 静默回路 | Engineering identity panel connected to a node-based activity stream | Sage grid, system language, and split-screen information architecture |
| Paper Orbit / 纸上星轨 | A personal growth system expressed as trajectories and orbiting topics | Circular visual grammar, playful color, and chronological learning trail |

Each direction includes a responsive home page and article page using the same real content.

## Round 1 — archived comparisons

These static prototypes compare four visual directions before the production site is rebuilt with Astro.

| Direction | Core idea | Best fit |
| --- | --- | --- |
| Signal Flow | A restrained engineering portfolio organized around one animated signal line | Balanced personal brand, projects, and writing |
| Field Notes | A practical lab notebook with annotations, ruled structure, and visible working context | Writing-first and highly personal |
| Night Build | A calm dark build console with deployment language and structured logs | Strong technical identity |
| Modular Index | A bold typographic index with asymmetric editorial modules | Most distinctive portfolio presentation |

Each direction includes a home page and an article page. All copy comes from the existing site or its stated content plan; the prototypes do not change the production site.
