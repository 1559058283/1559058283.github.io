本指南涵盖从注册域名到上线运营的全流程。重点是建立一套能够重复执行、能够验证、也能够回退的部署方法。

UPDATE

本站目前由 GitHub Pages 托管，推送源码后由 GitHub Actions 自动构建和发布。

[01]

前提准备

你需要一个域名和一个 GitHub 仓库。文章以 Markdown 保存，静态生成器把内容转换为浏览器可以访问的文件。

[02]

方案比较

MODEMAINTENANCEUSE_CASE
GitHub PagesLowStatic blog
Cloud serverHighBackend service
Vercel / NetlifyLowFrontend app
[03]

生成静态文件

生产构建应该可重复。依赖从锁文件安装，输出目录由持续集成任务生成。

$ npm ci
added dependencies from lockfile
$ npm run build
✔ generated static files
[04]

部署验证

检查页面状态码、HTTPS、自定义域名、手机布局和旧链接。构建成功只是开始，最终结果必须在线上验证。

  • PASS核心页面返回 200
  • PASSHTTPS 已强制启用
  • PASSwww 跳转到主域名
  • PASS保留迁移前版本标签
